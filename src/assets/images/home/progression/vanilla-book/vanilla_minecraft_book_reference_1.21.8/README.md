# Vanilla Minecraft book reference — Java 1.21.8

`enchanting_table_book.png` is the 64×32 texture atlas used by the Enchantment Table's animated book.

`enchanted_book_inventory_icon.png` is the separate 16×16 inventory icon.

Use the **Enchantment Table** texture for the website animation. It contains the cover, page, and binding areas intended for the book model; do not use the inventory icon as a cover texture.

The texture is unmodified. Minecraft assets remain the property of Mojang/Microsoft. For publication, follow the Minecraft Usage Guidelines and include the required non-official disclaimer.
