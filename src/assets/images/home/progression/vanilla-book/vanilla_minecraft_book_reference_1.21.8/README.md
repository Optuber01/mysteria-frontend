# Vanilla Minecraft book reference — Java 1.21.8

`enchanting_table_book_1.21.8.png` is the 64×32 texture atlas used by the Enchantment Table's animated book. `VanillaBookRig.vue` maps its cover, page and binding areas onto the website's 3D book.
